# FIND IT — Login UI Prototype

A standalone, static prototype of the FIND IT login page. It contains no server,
database, account system, or real sign-in.

## Preview

Open `index.html` in a browser, or start a local static server from this folder:

```powershell
python -m http.server 5500
```

Then visit <http://localhost:5500>.

The password visibility control, remember-me checkbox, forgot-password
explanation, and form feedback are interactive. Form feedback is demonstrative
only; credentials are not sent or saved. The page uses Google Fonts when
available and falls back to system fonts.
